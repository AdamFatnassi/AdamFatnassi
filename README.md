### 🏆 Featured Projects & Expertise

*   **📈 Quantitative Finance & StatArb:** Engineered a pairs trading framework on S&P 500 data utilizing Engle-Granger cointegration, Hidden Markov Models (HMMs) for market regime classification, and XGBoost.
*   **🧠 RAG & Generative AI:** Designed document parsing and chunking pipelines for regulatory decisions using PaddleOCR, PP-StructureV3, and Qdrant vector databases.
*   **⚙️ Full-Stack Rule Engines:** Developed an Oracle AWR report diagnostic engine utilizing Java, Spring Boot, Angular, and fuzzy logic to automate database performance tuning.
*   **🦠 Probabilistic Modeling:** Implemented multiply-connected Bayesian networks using `pyAgrum` and junction tree algorithms to model epidemiological risks and hospital saturation.
