## 🏗️ How I architect a RAG pipeline

A simplified view of the pipeline I built during my Generative AI internship at Ooredoo:

```mermaid
flowchart LR
    A[Web scraping] --> B[OCR<br/>PaddleOCR V5 / PaddleVL]
    B --> C[Structural segmentation]
    C --> D[Chunking]
    D --> E[(Qdrant<br/>vector DB)]
    Q[User query] --> F{Hybrid retrieval}
    E --> F
    F -->|exact ID lookup| G[Candidates]
    F -->|filtered ANN, k x 4 over-fetch| G
    G --> H[Cross-encoder reranking]
    H --> I[LLM answer]
```
